# OLED 重构验证记录

验证日期：2026-10-10。

## 实现结果

- 公共入口 `Int_OLED.h` 不依赖 HAL；硬件 I2C、地址转换、延时和错误转换集中在 `OLED_Port.c/.h`。
- 使用 1024 字节静态显存，绘制和刷新分离，按页批量发送脏列区间；无变化时不通信。
- 支持 6×8、8×16 字体、整行格式化输出、负数和小数、点线矩形圆及填充、区域清除和单色位图。
- 完整可打印 ASCII 字库及固定图片为 `const`；非法字符安全替换，像素和位图边界裁剪。
- 修复偶数列偏移、数字重叠与负数显示、短文字残影，以及页寻址模式参数。
- 主程序每 100 ms 刷新，先取得一致快照再恢复中断并格式化；初始化失败每 1 s 重试，刷新失败下个周期重试。
- Keil 工程已添加平台适配和字库源文件。未执行提交、推送或固件下载。

目标为 STM32F103RC，ARM Compiler V5.06 update 7（build 960），C99、Microlib。

| 项目 | 大小 |

验证产物位于 `MDK-ARM/.vscode/oled-validation/build/`，日志为其上级目录的 `build.log`。目录已被现有 `.gitignore` 忽略，不覆盖原工程的构建产物。

链接结果包含 Microlib 浮点格式化代码。`OLED_PrintLine` 自身静态栈大小为 192 字节；原工程栈为 1024 字节。链接器调用图包含不可追踪的函数指针/循环，静态报告不能替代运行时栈高水位测量。
