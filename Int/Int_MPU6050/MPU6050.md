# MPU6050 配置与使用说明

> 本文档对应 `Int/Int_MPU6050/` 下的驱动，配合 `Com/IIC/` 软件模拟 IIC 使用。

## 1. 概述

MPU6050 集成 3 轴陀螺仪 + 3 轴加速度计，通过 I2C 通信。本工程用软件模拟 IIC（PB3/PB4）驱动单颗 MPU6050，轮询方式读取原始 ADC 值，不做姿态解算（姿态解算为后续扩展，`IMU_Config.h` 里已预留 `Euler_struct` 与灵敏度宏）。

## 2. 硬件连接

| 信号 | MCU 引脚 | GPIO 模式 | 说明 |
|---|---|---|---|
| SDA | PB3 | 开漏输出 | 依赖外部 4.7kΩ 上拉 |
| SCL | PB4 | 开漏输出 | 依赖外部 4.7kΩ 上拉 |
| AD0 | GND | — | 7 位地址 = 0x68；接 VDD 则 0x69 |
| INT | PB7（已布线未用） | — | 当前轮询模式，未启用中断 |

I2C 地址字节：写 = `0xD0`，读 = `0xD1`（由 7 位地址 `0x68` 左移 1 位生成，见 `MPU6050_ADDR_WRITE/READ`）。

## 3. 寄存器配置

`Int_MPU6050_Init` 的初始化序列：

| 步骤 | 寄存器 | 地址 | 值 | 含义 |
|---|---|---|---|---|
| 1 | WHO_AM_I | 0x75 | 读 | 校验应 = 0x68，否则判设备不在线 |
| 2 | PWR_MGMT1 | 0x6B | 0x80 | DEVICE_RESET=1，复位全部寄存器 |
| — | — | — | HAL_Delay(100) | 等复位完成 |
| 3 | PWR_MGMT1 | 0x6B | 0x01 | CLKSEL=001（X 轴陀螺 PLL），SLEEP=0 唤醒 |
| 4 | PWR_MGMT2 | 0x6C | 0x00 | 六轴全部唤醒，无单轴待机 |
| 5 | USER_CTRL | 0x6A | 0x00 | 关 FIFO、关辅助 IIC 主机 |
| 6 | FIFO_EN | 0x23 | 0x00 | 不将任何传感器数据入 FIFO |
| 7 | INT_EN | 0x38 | 0x00 | 关所有中断（轮询模式） |
| 8 | CONFIG | 0x1A | 0x03 | DLPF_CFG=3，带宽 ~42 Hz |
| 9 | SMPLRT_DIV | 0x19 | 0x01 | 输出率 = 1 kHz/(1+1) = 500 Hz |
| 10 | GYRO_CONFIG | 0x1B | 0x18 | FS_SEL=3 → ±2000 °/s |
| 11 | ACCEL_CONFIG | 0x1C | 0x00 | AFS_SEL=0 → ±2 g |

**为何时钟源选 X 轴陀螺 PLL**：精度优于内部 RC，温漂更小，是推荐值。
**DLPF=3（~42 Hz）**：应用层 100 Hz（10 ms 周期）读取，留 2 倍余量，既滤掉高频抖动又不引入明显滞后。

## 4. 量程与灵敏度

| 传感器 | 量程 | 灵敏度 | 宏（`IMU_Config.h`） |
|---|---|---|---|
| 加速度 | ±2 g | 16384 LSB/g | `IMU_ACCEL_LSB_PER_G` |
| 陀螺 | ±2000 °/s | 16.4 LSB/(°/s) | `IMU_GYRO_LSB_PER_DPS` |

换算公式：

```
加速度 (g)   = raw / 16384.0
角速度 (°/s) = raw / 16.4
```

`raw` 为 `Gyro_Accel_Struct` 中的 `int16_t` 有符号原始值。

## 5. 软件 IIC 时序

SCL 半周期 = 2 µs（`I2C_DELAY`），时钟约 250 kHz，在 MPU6050 支持的 400 kHz 内。

| 信号 | 时序 |
|---|---|
| 起始 | SCL 为高时，SDA 由高变低 |
| 停止 | SCL 为高时，SDA 由低变高 |
| 数据位 | SCL 低时改 SDA，SCL 高时采样（MSB first） |
| 应答 | 第 9 个时钟，从机拉低 SDA = ACK |

## 6. 读写流程

**写寄存器**（3 字节 + 应答）：

```
START | 写地址(0xD0)+ACK | 寄存器地址+ACK | 数据+ACK | STOP
```

**连续读**（重复起始，burst read）：

```
START | 写地址(0xD0)+ACK | 寄存器地址+ACK |
START | 读地址(0xD1)+ACK | 读 N 字节(前 N-1 字节回 ACK, 末字节回 NACK) | STOP
```

代码见 `Int_MPU6050.c` 的 `MPU6050_Write_Reg` / `MPU6050_Read_Regs`。

## 7. 14 字节数据帧

从 `0x3B` 起连续读 14 字节（MPU6050 自动递增寄存器地址），保证六轴来自同一采样帧：

| 偏移 | 寄存器 | 字段 |
|---|---|---|
| 0, 1 | 0x3B, 0x3C | accel_x |
| 2, 3 | 0x3D, 0x3E | accel_y |
| 4, 5 | 0x3F, 0x40 | accel_z |
| 6, 7 | 0x41, 0x42 | 温度（本驱动不存） |
| 8, 9 | 0x43, 0x44 | gyro_x |
| 10, 11 | 0x45, 0x46 | gyro_y |
| 12, 13 | 0x47, 0x48 | gyro_z |

每字段高字节在前，`MPU6050_Sample` 组合成 `int16_t`（补码位模式自动解释，无需手动减法）。

## 8. 使用方法

模块自包含 `g_imu_data` / `g_imu_ready` 两个全局（在 `Int_MPU6050.c` 中定义，头文件 `extern`），其他模块 `#include "Int_MPU6050.h"` 即可直接读。

**上电（main.c）**：
```c
g_imu_ready = Int_MPU6050_Init();      /* 初始化一次 */
HAL_TIM_Base_Start_IT(&htim4);         /* 启动 TIM4 10ms 中断 */
```

**TIM4 10ms 中断（`App/Track_Task.c` 的 `HAL_TIM_PeriodElapsedCallback`）**：
```c
if (htim->Instance == TIM4) {
    Int_MPU6050_Tick();                /* 自动读六轴，刷新 g_imu_ready */
    TrackTask_Tick();
}
```

**主循环（main.c）只管通信失败重试**：
```c
if (g_imu_ready == 0U &&
    HAL_GetTick() - last_imu_retry_ms >= 1000U) {
    last_imu_retry_ms = HAL_GetTick();
    g_imu_ready = Int_MPU6050_Init();
}
```

静态时 `g_imu_data.accel.accel_z` ≈ ±16384（1g），`g_imu_data.gyro.*` ≈ 0；数据可在调试器 watch 窗口查看，或除以灵敏度宏转换为物理量。

> **数据竞争提示**：`g_imu_data` 在中断里更新，主循环或其他任务读取 28 字节结构体时若被中断打断会读到半新半旧。当前无下游消费者，暂不处理；将来要用 IMU 数据做控制时，读取处加 `__disable_irq()/__enable_irq()` 临界区或用双缓冲。

## 9. 常见问题

**`g_imu_ready` 一直为 0 / 读到 NACK**
- PB3/PB4 外部上拉电阻是否到位（开漏必须外接 4.7 kΩ）
- AD0 电平：接低才是 `0x68`，否则需改 `MPU6050_ADDR` 为 `0x69`
- 接线、供电（VDD 3.3 V）

**数据全 `0xFF`**
- I2C 通信失败（NACK），`Read_Regs` 返回 0，`frame` 未被写入
- 按上一条排查

**`accel_z` 静态不为 ±16384**
- 模块安装轴向：重力不在 Z 轴时，1 g 会分到其他轴
- 翻转板子，观察三轴变化是否合理

**陀螺零漂**
- 静态 `gyro_*` 不为 0 属正常现象，需在上层做零偏校准（静止时取均值作为偏置）
