# 运动状态机与 OLED 日志宿主验证

在工程根目录运行：

```powershell
./tests/motion/run_tests.ps1
```

脚本默认使用 `D:/CoderSpcace/IDE/mingw64/bin/gcc.exe`，找不到时从 `PATH` 查找 `gcc`。编译产物写入 `$env:TEMP/all-terrain-motion-tests`，不删除文件，不修改工程源码。可通过 `-Gcc` 和 `-BuildDirectory` 指定编译器及产物位置。

完整 Keil 验证使用 `./tests/motion/build_keil.ps1`。脚本复制当前工程到临时目录，
将源文件路径改为工作区绝对路径并完整重编译，AXF、HEX 和日志全部保存在该临时目录。
默认编译器入口为 `E:/Embedded_Development/KeilMDK/UV4/UV4.exe`，可用 `-Keil` 指定。
不会烧录硬件，也不会覆盖 Git 中的旧 `.o`、`.map` 等构建产物。

`test_motion_route.c` 编译真实 `Mode_FSM`、`Route`、`Debug_Log`、`Track_Task`、`IMU_Task`、`Com_pid` 与 `Com_Limit`。外设替身只提供灰度、IMU 采样状态、指定 yaw、电机输出记录以及 HAL 时间、OLED 显示总线。GNU 链接器包装 `PID_calc` 以统计控制器次数，内部继续执行真实 PID 计算。

测试验证：

- 每帧灰度采样、两套运动控制互斥、本帧采样后才允许角度 PID。
- 动作请求延后生效、最后请求覆盖、停车优先、中断屏蔽状态恢复，以及接受停车后本帧到来的新请求延至下一帧。
- 左右转后的循迹或 IMU 直行、角度基准重新建立、转后航向保留。
- 7°容差与连续三帧完成、300 帧超时、截止帧完成优先。
- IMU 读取失败、NaN/Inf、非法转后模式停车，以及显式恢复。
- 真实 PID 的最短角差、PWM 限幅与方向约定。
- 十字两帧、左右三帧确认、单次触发、类型变化不解锁、离开三帧重新允许触发。
- IMU 与停车期间的有线/无线条件、80 帧前移和 10 帧十字穿越。
- 外部指令打断路线、关闭路线保留当前动作、故障不能自动恢复、TIM4 唯一控制回调。
- 仅实际接受的动作写日志，被邮箱覆盖的请求不记录；10 ms 单帧路口事件在 100 ms OLED 刷新时仍然保留。
- 路口持续存在时不重复刷日志；循迹丢线使用 WARN，IMU 条件丢线使用 INFO。
- 故障发生前的 PWM、角度和动作帧数被锁存；停车及非法新请求不解冻，合法新动作恢复实时显示。

`test_debug_log.c` 独立编译真实 `Debug_Log.c`，用上层数据模拟实时和故障现场，检查实际生成的八行 OLED 文本：

- 三条日志按发生顺序显示，不足三条时最新一条仍在最后一行；超容量移除最旧记录。
- 毫秒转换为开机秒数、等级显示、11 字符截断、字符串值复制、空消息及非法等级忽略、控制字符替换、百分号安全。
- 循迹隐藏暂停采样的旧角度，本帧无效 IMU 隐藏 Y/E，最短角差正确。
- NaN/Inf 和超显示范围角度显示 `--`；最大时间、最大动作帧数和满幅 PWM 不超每行 21 字符。
- 首次故障现场和日志冻结、重复故障不覆盖、显式解除冻结保留历史；无故障原因不冻结。
- 快照复制后再发生的控制更新只反映到下一屏；全部格式化与 OLED 刷新在恢复原 PRIMASK 后进行。
- OLED 刷新失败原样返回，模拟通信恢复后完整重绘并保留日志。

OLED 替身先完整格式化再检查行宽，不通过裁剪隐藏布局错误。真实 OLED 驱动回归仍使用 `tests/oled` 下的独立测试。

`test_attitude.c` 独立编译真实 `Attitude.c`，验证姿态复位立即清零、`ready=0` 保留输出以及设置 yaw 偏置后的下一帧连续性。

全部测试使用 `-std=c99 -Wall -Wextra -Werror -pedantic`。OLED 替身不执行 `main.c` 中的一秒 `OLED_Init()` 重连分支；该分支通过源码审查和 Keil 编译检查，实际 OLED 断电、拔插及显示效果仍需板上验证。

2026-10-10 集成验证：11 组运动/路线、4 组日志和 1 组姿态测试通过；OLED 驱动回归的 2001 次核心检查与 47 次端口检查通过。Keil ARMCC 5.06 完整重编译为 0 Error(s)、0 Warning(s)，Code=27056、RO-data=3732、RW-data=176、ZI-data=2896 字节。宿主与编译结果不能替代板上 IMU 通信、实际车速和 PID 参数校准。
